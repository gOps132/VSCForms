# Washing_Machine_Timer-Fuzzy_Logic

simple fuzzy logic algorithm for a Washing Machine Timer that checks/categorizes 3 different inputs.
<ul>
  <li>Load amount (in kg)</li>
  <li>Soiling Level (range)</li>
  <li>Detergent Amount (in mL)</li>
</ul>

incorporates triangular and trapezoidal membership
